# 🚀 Деплой Tesla Model Ω на Vercel — с нуля до живого сайта за 15 минут

Сайт — одностраничный Next.js-лендинг без базы данных. На Vercel деплоится
бесплатно, карта не нужна. В конце получишь постоянную ссылку вида
`https://tesla-model-omega.vercel.app` с автоматическим HTTPS.

---

## Если первый деплой не удался — начни с чистого листа (самый надёжный путь)

Если в старый репозиторий попала старая или неполная версия сайта, проще
всего завести новый репозиторий и загрузить туда **этот** архив целиком.
В нём всё исправлено: шрифты лежат внутри сайта, и сборке не нужен интернет.

1. Скачай архив `tesla-site-final.zip` и распакуй его (правая кнопка →
   «Извлечь всё...»)
2. Открой распакованную папку и выдели **всё** внутри: `Ctrl+A` (Windows)
   или `Cmd+A` (Mac)
3. На GitHub: **`+`** (правый верхний угол) → **New repository** → имя
   `tesla-site` → **Create repository**
4. На странице пустого репозитория нажми ссылку **uploading an existing
   file** → перетащи все выделенные файлы и папки → **Commit changes**
5. **Проверка:** на главной странице репозитория сверху должны лежать папки
   `src`, `public` и файл `package.json`. Если видишь только одну папку —
   файлы попали не туда, удали их и повтори шаг 4
6. На Vercel: **Add New… → Project** → найди `tesla-site` → **Import** →
   ничего не меняй → **Deploy**
7. Через 1–2 минуты статус станет **Ready** → кнопка **Visit** откроет сайт

Старый репозиторий и старый проект Vercel можно не трогать — удалишь позже.

## Путь A — без командной строки (самый простой)

### 1. Создай репозиторий на GitHub

1. Залогинься на GitHub, нажми **`+`** в правом верхнем углу → **New repository**
2. Repository name: `tesla-model-omega`
3. Visibility: **Private** или **Public** — неважно
4. Ничего не добавляй (без README) → **Create repository**

### 2. Загрузи файлы сайта

1. На странице пустого репозитория нажми ссылку **uploading an existing file**
2. Распакуй архив `tesla-site-final.zip` на своём компьютере
3. Перетащи **содержимое** папки (все файлы и папки внутри, а не саму папку)
   в окно браузера
4. Дождись загрузки (файлов ~70) → внизу нажми **Commit changes**

> 💡 Если drag-and-drop не принимает всё сразу — перетащи файлы двумя партиями
> (сначала `src`, потом остальное). Либо используй Путь B.

### 3. Задеплой на Vercel

1. Залогинься на https://vercel.com через GitHub
2. Нажми **Add New… → Project**
3. В списке найди `tesla-model-omega` → **Import**
4. Все настройки оставь по умолчанию (Vercel сам определит Next.js) → **Deploy**
5. Подожди 1–2 минуты — сборка идёт автоматически

🎉 Готово! Vercel покажет ссылку вида `https://tesla-model-omega.vercel.app`.

## Путь B — через терминал (для тех, кто дружит с git)

```bash
# 1. Распакуй архив и зайди в папку

# 2. Создай репозиторий на GitHub (Путь A, шаг 1),
#    затем привяжи и запушь:

git add .
git commit -m "Tesla Model Omega — cyberpunk landing"
git branch -M main
git remote add origin https://github.com/ТВОЙ_НИК/tesla-model-omega.git
git push -u origin main

# 3. Деплой на Vercel (одна команда, ответь на вопросы — всё по умолчанию)

# для продакшена: npx vercel --prod
```

Альтернатива без терминала: приложение **GitHub Desktop**
(https://desktop.github.com) — Add existing repository → Publish.

## После деплоя

| Что | Как |
|---|---|
| Свой домен | Vercel → Project → **Settings → Domains → Add**. Vercel покажет DNS-записи (A `76.76.21.21` или CNAME `cname.vercel-dns.com`) — добавь их в панели регистратора домена |
| Обновление сайта | Меняешь файлы → `git push` → Vercel деплоит автоматически за ~1 мин |
| Превью веток | Каждая ветка и pull request получают отдельную ссылку |
| Логи сборки | Vercel → Project → **Deployments** → клик по деплою → **Building** |
| Переключение языка | Кнопка **EN / RU** в шапке сайта, выбор запоминается |

## Возможные проблемы

- **Build failed** — проверь в логах, что в репозиторий попали папки `src`,
  `public` и файл `package.json`. Частая причина — загрузилась только часть файлов.
- **Пустая страница** — обнови с Ctrl+Shift+R; первый деплой иногда отдаёт кэш.
- **Картинка машины не грузится** — убедись, что `public/tesla-neon.png` загружен.
- **Не находится репозиторий при Import** — на GitHub нажми имя репозитория →
  Settings → внизу **Change visibility**, или в Vercel нажми **Adjust GitHub App
  Permissions** и дай доступ к репо.

## Почему это бесплатно

Vercel Hobby-план: 100 GB трафика в месяц, безлимит статических страниц, HTTPS,
глобальный CDN. Для лендинга этого хватит с огромным запасом. Карта не
запрашивается. GitHub — безлимитные приватные репозитории.
